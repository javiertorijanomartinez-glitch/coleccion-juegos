# Colección de Juegos Web y Móviles

Este repositorio contiene 4 proyectos de juegos interactivos desarrollados para web y dispositivos móviles:

1. **Juegos de la Infancia (`game1/`)**:
   - 3 en Raya (*Tic Tac Toe*)
   - Conecta 4 (*Connect 4*)
   - Parchís
   - El juego de la Oca
   - Incluye versión ejecutable directa: `Juegos_Infancia.html`

2. **Piano Digital Móvil (`piano/`)**:
   - Teclado táctil interactivo con notas y síntesis de audio.
   - Incluye versión directa: `Piano_Movil.html` y script `iniciar_piano.bat`.

3. **El Impostor (`impostor/`)**:
   - Juego de deducción social y roles ocultos.
   - Incluye versión directa: `Impostor_Movil.html`.

4. **Puntitos (`puntitos/`)**:
   - Juego de unir puntos y conquistar casillas en cuadrícula.
